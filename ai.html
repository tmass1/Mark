Guide

Use Mark with your AI tools

Claude, ChatGPT, Cursor and other AI tools can ask Mark for a screenshot. You choose what they see, point at what matters, and press Send. Nothing is taken or sent without that Send.

How it works

  1. 1

    Your AI asks

    Mark comes forward with what it wants to see — Claude Code asks to see “the error in Xcode”. Nothing is captured yet.

  2. 2

    You show it

    Bring the thing on screen and capture it the usual way, with ⌘4 or a tile. Add arrows, boxes and numbered steps with notes, and hide anything private.

  3. 3

    You send it

    Press Send (⌥⌘C). Your AI gets the picture, what you marked and where, and the words in it, read on your Mac. Don’t Send or Esc tells it no.

Set it up once

First move Mark to your Applications folder and open it once. Then the quickest way is in Mark itself: open Settings › AI tools, pick your tool under Add Mark to, and press the button beside it. Or follow the steps for your tool here.

Claude Code

Command line
  1. Paste this into Terminal and press Return:
    claude mcp add --scope user mark -- '/Applications/Mark.app/Contents/MacOS/mark' --mcp
  2. Start a new Claude Code session. Mark is there in every project.

This is also how to set up Claude Code in VS Code and Cursor: Claude Code keeps one set of tools, wherever it runs, apart from the editor’s own.

Codex

Command line
  1. Paste this into Terminal and press Return:
    codex mcp add mark -- '/Applications/Mark.app/Contents/MacOS/mark' --mcp
  2. Start a new Codex session. ChatGPT’s Codex chats share these settings, so they get Mark too.

GitHub Copilot CLI

Command line
  1. Paste this into Terminal and press Return:
    copilot mcp add --timeout 3600000 mark -- '/Applications/Mark.app/Contents/MacOS/mark' --mcp
  2. Start a new Copilot session. The timeout gives you an hour to answer; without it, Copilot may stop waiting before you’ve taken the screenshot.

Grok Build

Command line
  1. Paste this into Terminal and press Return:
    grok mcp add mark -- '/Applications/Mark.app/Contents/MacOS/mark' --mcp
  2. Start a new Grok Build session. Grok Build also uses what Claude Code is set up with, so if you added Mark to Claude Code, it’s already there.

Grok Bot can’t use Mark: it works on a computer in the cloud, which can’t reach your Mac.

Claude Desktop

App
  1. Copy these lines: 
    {
  "mcpServers": {
    "mark": {
      "command": "/Applications/Mark.app/Contents/MacOS/mark",
      "args": ["--mcp"]
    }
  }
}
  2. In Finder, choose Go › Go to Folder, enter ~/Library/Application Support/Claude, and open claude_desktop_config.json in TextEdit. If the file is empty, paste the lines as they are. If it already has an "mcpServers" section, add just the "mark" entry to it.
  3. Save, quit Claude with ⌘Q, and open it again.

Claude Desktop waits only a minute for a screenshot, so Mark counts that minute down for you.

ChatGPT

App
  1. In ChatGPT, open Settings › MCP servers and click Add server.
  2. Name it mark and choose STDIO.
  3. In Command to launch, paste Mark’s location:
    /Applications/Mark.app/Contents/MacOS/mark
  4. Under Arguments, click Add argument and type --mcp.
  5. Click Save, then Restart.

Mark works in ChatGPT’s Codex chats, which use tools on your Mac. Its regular chats run in the cloud and can’t reach it.

Cursor

Editor
  1. Add to Cursor Cursor opens and asks whether to install Mark. Click Install.
  2. Ask in Cursor’s Agent chat.

This adds Mark to Cursor’s own Agent. Using Claude Code inside Cursor? Set up Claude Code instead: it keeps its own tools.

VS Code

Editor
  1. Add to VS Code VS Code opens Mark’s page. Click Install, and trust Mark when it asks.
  2. Ask in Copilot Chat in Agent mode, with a model that can see images.

This adds Mark to Copilot Chat. Using Claude Code inside VS Code? Set up Claude Code instead: it keeps its own tools.

Ask for a screenshot

Ask the way you’d ask a person sitting beside you. Naming Mark helps the first time.

  • “Use Mark to look at my screen — why is this button out of line?”
  • “Take a screenshot of the error in Xcode and tell me what’s wrong.”
  • “Look at the chart I have open and explain the spike.”

Your AI also asks on its own when seeing your screen would help. Either way, Mark shows you what it wants first, and sends nothing until you press Send.

If something’s not right

Mark says to move it to Applications
Run from Downloads or the disk image, macOS gives Mark a temporary home your AI tool can’t find again. Drag Mark to Applications, open it from there, and set your tool up again.
Your AI says it can’t reach Mark
Mark opens itself when asked, from where it was when you set the tool up. If you’ve moved it since, set the tool up again. Check that Let AI tools ask for screenshots is on in Mark’s Settings.
A countdown appears
Some tools stop waiting after a set time — Claude Desktop after a minute. Send before it runs out, or ask again.
Your AI doesn’t know what Mark is
Then Mark isn’t among its tools. Each tool keeps its own list — and Claude Code inside VS Code or Cursor uses Claude Code’s, not the editor’s, so set up Claude Code for it. After setting a tool up, start a new session.
Your AI doesn’t use Mark
Ask for it by name. In Cursor and VS Code, use Agent mode; in ChatGPT, a Codex chat.
Turning it off
Uncheck Let AI tools ask for screenshots in Mark’s Settings. Your tools are told it’s off, and nothing else changes.

Other tools

Any tool that runs MCP servers on your Mac can use Mark. Give it this command, with the argument --mcp:

/Applications/Mark.app/Contents/MacOS/mark

Chats on the web, and Grok Bot, run in the cloud and can’t reach your Mac. Paste instead: every capture lands on your clipboard as a PNG, and ⇧⌘L copies its numbered steps as text.
