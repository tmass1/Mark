## What's new

- **A guide to using Mark with AI tools.** Settings › AI tools has a link to it, open at the tool you picked: each one's setup step by step, how to ask for a screenshot, and what to do when something is off. It's at mark.tommymassaro.com/ai.
- **The tools most people use, and only those.** Claude Code, Codex, GitHub Copilot CLI, Grok Build, Claude Desktop, ChatGPT, Cursor and VS Code. ChatGPT is now set up in its own Settings, with Mark's path to paste.
- **Claude Code in VS Code or Cursor.** It keeps its own tools apart from the editor's, so it's set up as Claude Code; Settings now says so under each editor.
