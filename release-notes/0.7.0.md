## What's new

- **Let Claude ask for a screenshot.** Claude Code, Claude Desktop and other MCP apps can now ask Mark for one. Mark comes forward with what they want to see; you capture it and mark it up as usual, and Send gives them the picture, what you marked on it and where, and the words in it, read on your Mac, so Claude gets exact text. Nothing is taken or sent without that Send, and Don't Send tells them no. For an app that only waits a minute, as Claude Desktop does, the ask counts it down. Set it up from Settings, under AI tools.
- **A thumbnail, if you like.** Turn on "Show a thumbnail instead of the editor" in Settings, and a capture is copied at once and waits in the corner of the screen, as macOS's own does: click it to mark it up, drag it into any app as a file, or swipe it away. It never takes the focus from the app you're in.
- **A shortcut for each way in.** Window, Screen and Timed can each have a shortcut of their own, set in Settings beside Region's.
- Copy Text and Hide Sensitive now say they're still working when the Mac takes a few seconds to read the first time.
