## What's new

- **Add Mark to the AI tools you use.** Settings › AI tools now lists 20 of them — Claude Code, Codex, Grok Build, GitHub Copilot CLI, Gemini CLI, Claude Desktop, ChatGPT, Cursor, VS Code, JetBrains, Zed and more. Pick one and Mark adds itself the way that tool does it: Cursor and VS Code open and ask, the command-line tools get a command for Terminal, and the rest get the lines for their settings.
- The ask counts down only for a tool that will stop waiting, and only in its last ten minutes, by how long that tool actually waits.
